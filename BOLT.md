1. **User Sovereignty:** The USER is the ultimate authority.

3. **Atomic Task Chunking:** Maximum 5 open tasks in `WORK_LOG.md` at any time.
4. **Git Checkpoints:** Every completed task must produce a Git commit with prefix `checkpoint: [ACTION]` and log the SHA to `WORK_LOG.md`.
5. **No Mocks, No Simulations:** 100% production code only.
6. **Zero Privilege Escalation:** Blocked on `sudo`, `rm -rf /`, `chmod -R 777`.

## 🧹 2. Token Cleaning & Context Reduction Protocol

To minimize token usage and prevent context overflow when working in WebContainers or cloud environments:

1. **Forbidden Context Ingestion:**
   - NEVER read or load into LLM context:
     - `local_py/**` (contains hundreds of discovery cache JSONs exceeding context limits)
     - `.venv/**`, `node_modules/**`, `dist/**`, `build/**`
     - `.git/**`, `.cache/**`, `exports/**`, `*.log`
2. **Surgical Diff Generation:**
   - Propose changes as targeted diffs / replacement blocks.
   - Do NOT rewrite or echo unmodified lines or entire multi-thousand-line files.
3. **Automated Token Audit:**
   - Before committing or requesting approval, verify staged files:
     ```bash
     python3 git_bolt_jules_gate.py audit
     ```
   - Generate token-compressed diffs:
     ```bash
     python3 git_bolt_jules_gate.py clean-diff
     ```

## 📊 3. Telemetry & Observability Directives

Bolt MUST track and log all AI operations to maintain complete observability:

1. **Per-Call Metrics:**
   - Every LLM interaction is automatically recorded in SQLite `research.db` via `src.antigravity_core.telemetry`.
   - Metrics tracked: `prompt_tokens`, `completion_tokens`, `total_tokens`, `cached_tokens`, `tokens_saved`, `latency_ms`, `cost_estimate_usd`.
2. **Commit / PR Telemetry Badge:**
   - Every Git checkpoint commit or PR generated by Bolt must include the telemetry badge:
     ```bash
     python3 git_bolt_jules_gate.py badge --agent bolt --action "[ACTION_NAME]"
     ```
   - Example Badge:
     > 📊 **Telemetry (BOLT)**: 1,420 tokens used | ⚡ 3,850 tokens saved | ⏱️ 280.5ms | 🤖 `gemini-3.7-flash`
3. **Live Dashboard:**
   - Review cumulative token savings and costs anytime:
     ```bash
     python3 git_bolt_jules_gate.py telemetry
     ```
